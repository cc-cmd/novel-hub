## 依据番茄发布技能的调整（相对设计文档 / 初版需求；2026-10-31 已确认采纳）
1. **发布状态增加「审核中」**（REQ-03 / 04 / 06）：覆盖已发布章节会重新审核，审核中不可改。
2. **content_hash 改为"发布形态 hash"**（REQ-02 / 04）：标题（H1）+ 转换后正文，忽略纯 Markdown 写法差异。
3. **标题以文件内 H1 为准**（REQ-02 / 05）：支持两种写法：`# 第N章 标题` 与 `# 《书名》· 第N章 · 标题`，章号须与文件名一致。
4. **小说可配置章节目录** `chapter_subdir`（REQ-01 / 02）：章节在子目录 `改稿/`，根目录是其他资料。
5. **复制拆分为 标题 / 正文 / 标题+正文**（REQ-05）；`- x` 转 `· x`，转换规则以技能为基准。
6. **字数口径确认**：发布形态正文的非空白字符数，不含标题（REQ-02）。

## UX 基准（MVP 版本）
- 基准原型：[Novel Hub UI 设计 · MVP 版本](https://claude.ai/artifact/5qTYWHaaX2M4goaaw3EYSY)（4 个可点击页面 + 空状态与错误状态 + 视觉规范）。原型数据均为示意。
- 各需求 **§6 页面与交互** 是该原型的文字版，与原型必须一致；一方变更时同步修改另一方。
- 分歧处理：**业务规则**（状态、口径、数据保护）以需求文档为准；**交互与布局**（入口位置、面板形式、文案、视觉）以原型为准。

### 全局 UX 约定
- **导航**：顶部固定「看板」「设置」；详情页、编辑页顶部提供返回链接，导航高亮「看板」。
- **发布徽标**（颜色 + 图标 + 文字）：○ 未发（白底灰边）、◷ 审核中（浅蓝）、✓ 已发（实心蓝）、↻ 需更新（橙）、! 文件丢失（红色虚线边）。
- **内联展开优先于弹窗**：添加目录、管理平台、解绑确认、移除确认、徽标操作、复制方式均在当前页内联展开。
- **操作反馈**：页面内提示条展示结果；取消发布状态时提示条提供「撤销」。错误显示在触发位置附近。
- **字体**：书名与编辑区正文用 Noto Serif SC，界面用 Noto Sans SC，章号、数字、路径用 JetBrains Mono。
- **无障碍与响应式**：可点击区域不小于 44px；窄屏工具栏换行，章节表格在容器内横向滚动。
