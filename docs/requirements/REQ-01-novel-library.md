## 1. 背景与目标

作者本地有多本小说，每本是一个目录，里面是 `ChNN-标题.md` 章节文件。平台需要知道"去哪里找小说"，并把每个子目录识别为一本小说，纳入统一管理。

**目标**：用户配置一个或多个"小说根目录"，系统自动把根目录下每个一级子目录识别为一本小说；用户可归档不再关注的小说。

## 2. 用户故事

- 作为作者，我想添加我存放小说的文件夹，这样平台能自动列出我所有的书。
- 作为作者，我想配置多个根目录（如不同磁盘/项目），书都能集中在一处。
- 作为作者，我想把已完结或暂停的书归档，让看板更清爽，且不影响我的文件。
- 作为作者，我想在新建了一本书的目录后，点击"重新扫描"就能看到它。

## 3. 范围

### 3.1 包含
- 小说根目录的添加、移除、列表展示（设置页 + 看板入口）
- 扫描根目录，一级子目录 = 一本小说
- 小说的归档 / 取消归档
- 目录不存在、无权限的提示

### 3.2 不包含
- 在平台内创建/重命名/删除小说目录（文件系统由用户自己管理）
- 递归扫描多层目录（只看根目录的一级子目录）
- 文件监听（仅"打开页面"与"重新扫描"触发）
- 删除小说记录（仅归档）

## 4. 业务规则与口径

1. **`dir_path` 全局唯一**：同一目录只能对应一本小说，即使被两个根目录覆盖（根目录嵌套）。
2. **小说名取目录名**，目录被用户在磁盘上重命名后，视为"原目录丢失 + 新目录新增"（`dir_path` 是身份标识）。MVP 不做迁移（见 §11 Q2）。
3. **文件是真相**：平台不创建、不修改、不删除小说目录。
4. 扫描是幂等的：重复执行不产生重复记录。

## 5. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| F1.1 | 添加根目录 | 用户输入/粘贴绝对路径提交。校验：路径存在、是目录、可读。校验失败给出明确原因，不保存。 |
| F1.2 | 根目录去重 | 同一绝对路径（规范化后，去末尾斜杠、解析 `..`）不可重复添加。 |
| F1.3 | 移除根目录 | 从配置中移除；该根目录下已入库的小说**保留记录**，标记为"根目录已移除"（见 §11 Q1）。不删除任何磁盘文件。 |
| F1.4 | 扫描根目录 | 遍历每个根目录的一级子目录，每个子目录视为一本小说；隐藏目录（以 `.` 开头）及非目录项忽略。 |
| F1.5 | 新小说入库 | 子目录未入库 → 新建 `novel`：`name` = 目录名，`dir_path` = 绝对路径，`archived = false`。 |
| F1.6 | 已有小说保持 | `dir_path` 已存在 → 不重复创建，保留其 `archived` 与用户设置。 |
| F1.7 | 小说目录消失 | 已入库小说的目录不再存在 → 保留记录，列表中标记"目录丢失"，不自动删除、不自动归档。 |
| F1.8 | 触发时机 | 打开总览看板时自动扫描一次；点击"重新扫描"手动触发。扫描结果同时触发各小说的章节同步（见 REQ-02）。 |
| F1.9 | 归档 / 取消归档 | 归档仅设置 `archived = true`，从看板默认列表隐藏；不移动、不修改磁盘文件。可在"已归档"视图中查看并取消归档。 |
| F1.10 | 归档小说不参与扫描同步 | 归档的小说在扫描时只确认目录是否存在，不同步章节，减少开销。取消归档后立即同步一次。 |
| F1.11 | 章节目录 | 每本小说可配置「章节目录」`chapter_subdir`（相对 `dir_path` 的子目录，默认空 = 小说根目录）。例：小说《陈波宁传》的章节文件在 `改稿/` 下，其余资料（设定集、`Act1-崩塌/` 等）不是章节。章节同步（REQ-02）只读取该目录（一级、不递归，`_v1` 等子目录自动忽略）。可在小说卡片菜单或详情页修改，修改后立即同步一次；原目录下章节若不再出现，按文件丢失处理（REQ-02 F2.4）。目录不存在时给出提示。 |

## 6. 页面与交互

原型：设置、总览看板、小说详情、空状态与错误状态（见 [README「UX 基准」](README.md)）。

- **设置页 `/settings` → 小说根目录区**
  - 列表每行：路径（等宽）+ 状态行。状态文案："正常 · 已识别 N 本小说"／"目录不存在 · 已有记录保留"／"无读取权限 · 已有记录保留"。
  - 底部"添加目录"输入框 + "添加"按钮，错误显示在输入框下方，输入后清除。
  - 每行"移除"：点击后该行内联展开确认，文案"移除后其下小说保留记录，磁盘文件不受影响。"，按钮"确认移除""取消"。
- **总览看板 `/`**
  - 顶部"添加小说目录"：在页内展开面板（路径输入、"添加并扫描""取消"），校验规则与设置页相同；成功后收起面板并提示"已添加 {路径}，扫描完成"。
  - 顶部"重新扫描"、"显示已归档"开关。有根目录不可访问时，顶部显示警告条，附"前往设置处理"。
- **小说卡片**：⋯ 菜单含"重新扫描此书""设置章节目录"（跳转详情页）"归档 / 取消归档"。归档提示"已归档《X》，磁盘文件未改动"；取消归档提示"已取消归档《X》，章节已同步"。
- **小说卡片标签**：目录丢失（红色虚线）、根目录已移除（灰）、已归档（灰）。已归档卡片底色弱化，排在末尾。
- **小说详情页 → 章节目录**：标题区显示"章节目录：改稿/ [修改]"；点"修改"就地变为输入框 +"保存并同步"，留空表示小说目录本身。

| 校验场景 | 提示文案 |
|---|---|
| 输入为空 | 请输入目录的绝对路径 |
| 相对路径 | 路径不存在：请使用绝对路径 |
| 路径不存在 | 路径不存在：{路径} |
| 指向文件 | 不是目录：{路径} |
| 无读取权限 | 无读取权限：{路径} |
| 规范化后重复 | 该目录已添加，无需重复添加 |

## 7. 数据

使用 `novel` 表：`id, name, dir_path (唯一), chapter_subdir (默认空), archived, created_at`。其中 `chapter_subdir` 为对设计文档的补充（依据真实项目目录结构，见平台前置须知 §5）。

根目录配置需要持久化（设计文档未单列表，建议新增 `library_root(id, path 唯一, created_at)`，或存入设置表）——**属于对设计文档的补充，需实现前确认**。

## 8. 异常场景

| 场景 | 期望行为 |
|---|---|
| 添加不存在的路径 | 拒绝，提示"路径不存在：{路径}" |
| 添加的是文件而非目录 | 拒绝，提示"不是目录：{路径}" |
| 无读取权限 | 拒绝并提示"无读取权限：{路径}"（添加时）/ 页面提示并保留已有记录（扫描时） |
| 扫描过程中某根目录不可访问 | 该根目录显示错误状态，其他根目录照常扫描，已有记录不动 |
| 子目录无读取权限 | 该小说标记异常，不中断整体扫描 |

## 9. 验收标准

- **AC1.1** **Given** 根目录 A 下有 3 个子目录，**When** 添加 A 并扫描，**Then** 看板出现 3 本小说，名称为各目录名。
- **AC1.2** **Given** 已扫描，**When** 在 A 下新建子目录 B 并点击"重新扫描"，**Then** 看板新增小说 B，原有 3 本不重复。
- **AC1.3** **Given** 某小说已归档，**When** 查看看板默认视图，**Then** 不显示该小说；开启"显示已归档"后可见，且磁盘文件无任何变化。
- **AC1.4** **Given** 已入库的小说目录被删除，**When** 重新扫描，**Then** 该小说仍在，标记"目录丢失"，其发布记录未被删除。
- **AC1.5** **Given** 添加不存在的路径，**When** 提交，**Then** 提示错误且未生成任何记录。
- **AC1.6** **Given** 同一路径（含末尾 `/`）重复添加，**Then** 第二次被拒绝。
- **AC1.7** **Given** 一次扫描执行两次，**Then** 数据库中小说数量不变。

## 10. 测试建议

- 单元：路径规范化与去重、子目录识别（忽略隐藏项/文件）。
- 手动：§9 验收标准全部场景；权限不足目录。

## 11. 待确认问题

| # | 问题 | 当前假设 |
|---|---|---|
| Q1 | 移除根目录后，其下小说如何处理？ | 保留记录并标记"根目录已移除"，仍可正常使用；不影响发布记录。 |
| Q2 | 磁盘上重命名了小说目录，发布记录是否需要迁移？ | MVP 不迁移，会出现一本"目录丢失"旧书和一本新书。后续可加"合并/重新指向目录"。 |
| Q3 | 根目录本身也可能直接是一本小说（章节文件就在根目录下）吗？ | 不支持，根目录只作容器。 |
| Q4 | 空目录 / 没有任何 `ChNN-*.md` 的子目录是否算小说？ | 算，入库为 0 章的小说（用户可能刚建目录）。 |
| Q5 | 同一小说有多版本稿（如 `发布包/正文/*.txt` 原稿、`改稿/*.md` 改稿）怎么办？ | MVP 一本小说只跟踪一个章节目录，通过修改 `chapter_subdir` 切换版本；`.txt` 原稿不识别（仅 `.md`）。多版本并存列为后续。 |
