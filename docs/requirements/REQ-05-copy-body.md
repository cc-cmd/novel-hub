## 1. 背景与目标

作家后台（番茄、起点等）以纯文本方式粘贴发布，而本地稿件是带 Markdown 标记的 `.md`。每次手工删除 `#`、`**` 既慢又易错。

**目标**：在列表和编辑页一键把"标题 + 正文"转成**纯文本**并写入剪贴板，可直接粘贴到平台后台。

## 2. 用户故事

- 作为作者，我想点一下"复制"，就能直接去作家后台粘贴，不用手工清理格式。
- 作为作者，我在编辑页改完后，想复制"标题+正文"一起粘贴。
- 作为作者，我想知道复制成功了，且复制的是最新保存的内容。

## 3. 范围

### 3.1 包含
- Markdown → 纯文本的转换规则
- 默认复制格式："标题 + 换行 + 正文"
- 详情页每行"复制 ▾"、编辑页"复制标题+正文"
- 复制成功/失败反馈

### 3.2 不包含
- 复制格式的可视化模板配置（MVP 仅内置默认格式，设置页只读说明，见 Q1）
- 复制为富文本 / HTML
- 复制为 HTML（平台后台接受纯文本粘贴，无需 HTML）
- 复制后自动标记已发（保持"手动标记"，避免误操作）

## 4. 业务规则与口径

### 4.1 输出格式

#### 整体结构

```
{标题}
{空行}（见 Q3）
{去标记后的正文}
```

设计文档表述为"标题 + 换行 + 正文"。**默认：标题一行，其后空一行，再接正文**；若你希望标题后不留空行，可在 Q3 调整。

#### Markdown 去标记规则

| Markdown | 处理 | 示例 |
|---|---|---|
| 标题 `# ` ~ `###### ` | 去掉井号和后随空格，保留文字 | `## 第一节` → `第一节` |
| 粗体 `**x**` / `__x__` | 去标记保留文字 | `**重要**` → `重要` |
| 斜体 `*x*` / `_x_` | 去标记保留文字 | `*低语*` → `低语` |
| 删除线 `~~x~~` | 去标记保留文字 | |
| 行内代码 `` `x` `` | 去反引号保留文字 | |
| 引用 `> x` | 去 `> `，保留文字 | |
| 无序列表 `- x` / `* x` | 转为 `· x`（与番茄发布技能一致，保留列表感）；`+ x` 同 | |
| 有序列表 `1. x` | **保留**序号（小说中罕见，保守处理，见 Q4） | |
| 链接 `[文字](url)` | 保留"文字"，丢弃 url | |
| 图片 `![alt](url)` | 整体移除（纯文本无法承载） | |
| 分隔线 `---` / `***` | 转为空行（或保留一空行） | 小说中常用于场景切换，见 Q5 |
| 代码围栏 ```` ``` ```` | 去掉围栏行，保留内部文字 | |
| HTML 注释 `<!-- -->` | 整体移除 | |
| 转义 `\*` | 还原为字面量 `*` | |

**小说特殊注意**：对话/拟声词中的字面 `*`（如 `*砰*`、`***`）可能被误判为 Markdown。规则按"成对才去标记"处理，孤立 `*` 保留（见 Q6）。

#### 空白与换行规范

1. 换行统一为 `\n`。
2. 连续 3 个及以上空行压缩为 1 个空行。
3. 去除每行行尾空白。
4. 去除整体首尾空白。
5. **段落缩进（如全角空格 `　　`）保留**——很多作者用其排版，且平台后台常自行处理。（见 Q7）

### 4.2 业务规则

1. 复制是只读操作。
2. 去标记为**单向、有损**转换；原稿 `.md` 永不被修改。
3. 同一输入得到同一输出（确定性），便于测试与对比。
4. 转换在服务端或前端均可，但**必须只有一份实现**（建议放 `lib/publish.ts`，前端调用同一函数），避免两端结果不一致。

## 5. 功能需求

| 编号 | 需求 |
|---|---|
| F5.1 | 提供纯函数 `formatForCopy(title, markdown): string`，位于 `lib/publish.ts`，无副作用，供单测。 |
| F5.2 | 详情页每行有"复制 ▾"分裂按钮：主按钮复制「标题+正文」（设计文档默认格式），点 ▾ 在该行下方展开「仅标题」（`第N章 标题`）「仅正文」。原因：番茄作家后台标题与正文是两个独立输入框。 |
| F5.3 | 编辑页顶部有"复制标题+正文"按钮；复制的是 **textarea 当前内容**还是**已保存的文件内容**？默认复制**当前编辑框内容**（所见即所复制），并在有未保存修改时给出轻提示"复制的是未保存内容"（见 Q8）。 |
| F5.4 | 详情页复制时，**读取磁盘上最新文件**（而非库中缓存），保证与文件一致。 |
| F5.5 | 使用 `navigator.clipboard.writeText`；在不可用环境（非 HTTPS/非 localhost、权限拒绝）降级为临时 textarea + `document.execCommand('copy')`。 |
| F5.6 | 复制成功显示提示条："已复制《第N章 标题》，共 {N} 字"（字数口径同 REQ-02）；仅标题时为"已复制标题：第N章 标题"；失败显示错误并提示手动复制（显示含文本的只读框）。 |
| F5.7 | `file_missing = true` 的章节，"复制 ▾"置灰并提示"文件丢失"。 |
| F5.8 | 复制**不改变**任何状态：不标记已发、不更新库、不写文件。 |
| F5.9 | 标题取 REQ-02 解析出的 H1 标题（两种 H1 写法均可，章号取文件名序号），复制时输出平台标题格式 `第N章 标题`；正文中的**首行 H1 整行移除**，不在正文重复出现。无 H1 时用 `chapter.title` 拼 `第N章 ` 前缀。 |

## 6. 页面与交互

原型：小说详情、章节编辑、设置、空状态与错误状态（见 [README「UX 基准」](README.md)）。

- **详情页 `/novels/[id]`**：每行操作区"复制 ▾"（F5.2）。点击 → 提示条；按钮短暂变为"已复制 ✓"（1.5 秒）。文件丢失的章节按钮置灰。
- **编辑页**：顶部"复制标题+正文"，与"保存"并列，互不影响；结果显示在底部状态栏，有未保存修改时为"已复制，复制的是未保存内容"。
- **设置页 → 复制格式**：只读说明 +"本地文件 / 复制结果"对照示例，不可配置。
- 复制失败：显示"无法写入剪贴板，请手动全选复制"和可全选的只读文本框。

## 7. 数据

不新增表或字段，仅读取 `chapter` 等已有数据。

## 8. 异常场景

| 场景 | 期望行为 |
|---|---|
| 剪贴板 API 不可用 / 权限被拒 | 降级方案；仍失败则展示可手动复制的文本框 |
| 文件读取失败（权限/丢失） | 提示错误，不写剪贴板 |
| 正文为空 | 仍复制标题；提示条显示"正文为空" |
| 超长章节（> 5 万字） | 正常复制；无需特殊处理 |
| 含非常规 Markdown（表格、脚注） | 保守处理：保留原文字，不保证美观（小说场景罕见） |

## 9. 验收标准

- **AC5.1** **Given** 正文含 `## 小节`、`**加粗**`、`*斜体*`，**When** 点击复制，**Then** 粘贴内容无 `#`、`*`，文字保留。
- **AC5.2** **Given** `[文字](http://x)`，**Then** 复制结果为"文字"。
- **AC5.3** **Given** `![图](a.png)`，**Then** 复制结果不含该图片。
- **AC5.4** **Given** 第 1 章标题为"开端"，**When** 复制，**Then** 结果首行为"第1章 开端"，其后为正文，标题不重复。
- **AC5.5** **Given** 正文含连续 5 个空行，**Then** 复制结果仅保留 1 个空行。
- **AC5.6** **Given** 孤立的 `*砰*`成对 / 单个 `*` 字符，**Then** 成对者去标记，单个保留。
- **AC5.7** **Given** 点击复制，**Then** 章节状态、数据库、文件均无变化。
- **AC5.8** **Given** 在外部编辑器改稿未重新扫描，**When** 详情页点击复制，**Then** 复制的是磁盘最新内容。
- **AC5.9** **Given** 章节文件丢失，**Then** 复制按钮置灰。
- **AC5.10** **Given** 剪贴板权限被拒，**Then** 显示可手动复制的文本框。

## 10. 测试建议

- `publish.formatForCopy`：逐条覆盖 §4.1「Markdown 去标记规则」表每种语法；空白规范（压缩空行、行尾空白、首尾空白）；标题去重；空正文；幂等（对结果再次格式化不再改变）。
- 手动：真实粘贴到番茄/起点后台，观察段落、缩进是否符合预期（用以校准 Q2/Q5/Q7）。
